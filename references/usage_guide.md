# Markdown to Word Converter - 使用指南
> 完整 CLI 参数、字段说明与特性表见 SKILL.md。本文件为补充参考。

## 安装
```bash
pip install python-docx
```

可选依赖（用于代码块语法高亮）：
```bash
pip install pygments
```

## 样式自定义与扩展
转换器默认会自动读取脚本及 SKILL 同目录下的 `custom_styles.json` 文件。你可以直接通过修改该 JSON 文件来快速定制全套文档样式：
* **更改标题字体与字号**：修改 `main_title`（H1）、`chapter_title`（H2）等对象的 `size`、`latin` 与 `eastasia` 属性。
* **调整正文行距**：修改 `body` 对象下的 `line_spacing`（`1.0` 为单倍，`1.5` 为1.5倍）与 `space_after`（段后距）。
* **改变段落对齐**：修改对应对象的 `alignment`（`0` 代表左对齐，`1` 代表居中对齐）。
* **调整列表符号大小**：`list.bullet_size` 默认 `"auto"`（与列表正文同字号）；也可填数字或按层级数组。不建议大于正文字号，否则行高被抬高、列表间距反而大于正文。
* **开关行内代码样式**：`code.inline_code` 为 `true` 时行内代码使用 Consolas + 浅灰底；为 `false`（当前配置）时仅去掉反引号、按正文样式渲染。

## 测试示例（回归验证）
`templates/example.md` 按 SKILL.md「转换规则约定」逐节设计，**每节标题即对应一条规则**，条目里给出「源码写法 → 预期渲染结果」。重新生成示例文档（会覆盖 `templates/example.docx`，使其与 `.md` 保持同步）：
```bash
python scripts/markdown_to_word.py templates/example.md -o templates/example.docx
```
或按目录输出：
```bash
python scripts/markdown_to_word.py templates/example.md --output-dir templates/
```

打开 `templates/example.docx` 检查以下特性：

### 结构与文本
* **标题层级（Heading 1-6）**：`#`~`######` 依次映射 Word Heading 1-6；H4~H6 共用 `subsection_title` 样式（黑体 12pt 加粗），H1 居中、H2/H3 左对齐。
* **标题后空行**：源文件中标题下方的空行被跳过，转换后标题与正文之间不出现空段落（见「标题层级映射」一节首段）。
* **标题内行内代码**：`### 标题中的行内代码 cost_per_click` 的反引号被去掉，内容仍按标题字体渲染。
* **中西文字体分流**：正文中文宋体、西文 Calibri；标题黑体/微软雅黑；中英混排处不出现字体跳变。
* **双引号字体**：中文双引号 `“”` 被拆成独立 run 并用东亚字体渲染；「中英混排与双引号字体」一节的末段是纯英文段落，其中的 `"quoted"` 与 `(parentheses)` 保持半角，可与中文引号对比字重。
* **粗体/斜体语法**：仅星号写法生效；`__下划线粗体__`、`_下划线斜体_` 原样保留字符；`example_file_name` 这类标识符不被破坏、下划线不被吃掉。
* **标点替换**：符号前/后为中文或括号内含中文时，替换为中文引号与中文括号；纯英文句子、`(popularity)` 这类纯西文括号保持半角；引号被粗体拆开时仍成对替换。
* **路径保护**：`C:\Users\user1\示例(最终)文档.md`、`https://example.com/a_(b)?q=1`、`./docs/(示例)/example.md` 中的括号保持半角。
* **空格归一化**：中英、中数字、中文与中文之间都去空格；字母与运算符贴合（`x=1+2`）；半角标点前、全角标点两侧去空格；连续空格、制表符、全角空格 U+3000、不间断空格 U+00A0 一并归一化；英文单词之间、数字之间的空格保留。段落开头的全角缩进（前面没有汉字）保留。
* **单位/科学符号**：`30 ℃`→`30℃`、`90 ％`→`90％`、`90 %`→`90%`、`A → B`→`A→B`、`25 ° C`→`25°C`、`误差 ≤ 5 %`→`误差≤5%`；`Cool to 30 ℃ and hold.` 只在符号右侧对英文单词保留一个空格；`a ≠ b` 中字母两侧空格保留（`≠` 不在「字母也贴合」组）。

### 列表
* **无序四级符号**：`•` / `◦` / `▪` / `▫` 依次对应 0 / 4 / 8 / 12 空格缩进，左缩进实测约 0.10 / 0.35 / 0.60 / 0.85 英寸。
* **悬挂缩进**：长条目折行后第二行左边缘与首行正文对齐，而不是与圆点对齐（「无序列表与多级符号」最后一节）。
* **符号后多空格归一化**：源文件 `-     文本` 只渲染为一个空格。
* **有序编号尊重源编号**：源写 3/4/5，输出仍是 3/4/5。
* **紧凑写法自动递增**：连续三条都写 `1.`，输出为 1/2/3。
* **松散列表**：条目之间夹空行或正文时，仍按源编号 1/2/3 渲染，不重排。
* **打断后重新开始**：列表被正文中断，后续列表从 1 重新计数。
* **`1)` 写法**：源文件 `1)` 渲染为 `1.`。
* **混合嵌套**：无序套有序、有序套无序；2 空格也视为 1 级，4 空格为 2 级；子列表编号不串到父级。
* **任务列表**：状态属性 `w:sdt` 在 Word 中识别为「复选框内容控件」（Type=8），勾选态 ☑、未勾选 ☐，点一次切换一次，不再出现「点一下变叉、再点变空框」。
* **列表样式与正文区分**：列表段后距 2pt（正文 3pt），符号字号默认等于列表正文字号。

### 块级元素
* **代码块**：Consolas 等宽 + 浅灰底（F5F5F5）；带语言标记的按 Pygments 上色，未装降级为纯文本。代码本体原样保留，注释内容按正文规则清理。
* **引用块**：多行 `>` 合并为一个段落（段内软换行），左侧灰边框 + 浅灰底 + 斜体灰字。
* **表格**：3 列 6 行，Table Grid 网格边框、首行表头加粗、单元格上下内边距 3pt。
* **链接**：蓝色 `#0000FF` + 单下划线、可点击跳转；`example.com` 这类无协议地址自动补 `https://`。
* **分隔线**：`---` 整行删除，不渲染线条，也不因此多出空段。
* **图片（示例未包含）**：`![alt](本地路径)` 居中显示、宽 6 英寸、图注居中、比正文小 1pt、灰色斜体。示例文档为避免路径失效未放图片，可自备本地图片单独验证；URL 图片会被警告并跳过。

## 支持的 Markdown 语法速查
| 语法 | 支持 | 转换结果 |
| --- | --- | --- |
| `#` ~ `######` 标题 | ✅ | 映射 Heading 1-6，并继承 `custom_styles.json` 样式 |
| `**粗体**`、`*斜体*` | ✅ | Run 级加粗 / 斜体，可与行内代码、链接混排 |
| `__粗体__`、`_斜体_` | ❌ | 不解析，下划线原样保留（避免误伤标识符） |
| 反引号包裹的行内代码 | ✅ | 去反引号；`inline_code: true` 时 Consolas + 浅灰底，`false` 时按正文样式 |
| `[文本](URL)` | ✅ | 原生超链接，蓝色 + 单下划线；无协议时自动补 `https://` |
| `[文本](mailto:…)` | ✅ | 同上，可点击唤起邮件客户端 |
| `![alt](本地路径)` | ⚠️ | 仅本地图片，居中 6 英寸 + 图注；网络图片需先下载 |
| `- 项目`（多级） | ✅ | 符号 `•`/`◦`/`▪`/`▫` + 悬挂缩进，符号后固定一个空格 |
| `1. 项目`、`1) 项目` | ✅ | 尊重源编号；连续 `1.` 自动递增；被正文打断后重新从 1 开始 |
| `- [x]`、`- [ ]` | ✅ | `w:sdt` + `w14:checkbox` 复选框内容控件，勾选 ☑ / 未选 ☐，点击可正常切换 |
| 三个反引号的围栏代码块 | ✅ | 等宽 + 浅灰底；带语言标记且装了 Pygments 时高亮；代码本体原样保留，注释内容按正文规则清理 |
| `> 引用` | ✅ | 多行合并为一段，左侧边框 + 浅灰底 + 斜体 |
| `\| a \| b \|` 表格 | ✅ | 网格边框 + 表头加粗；单元格内不支持转义竖线 |
| `---` 分隔线 | ✅ | 整行删除，不渲染线条、不留空行 |
| `\(A \rightarrow B\)` 等 LaTeX 行内式 | ✅ | 去定界符并把常用宏转 Unicode：`→ ← ↔ ⇒ ⇔ ↑ ↓ ≤ ≥ ≠ × ÷ ± ≈ ∞` |
| 脚注 / 复杂数学公式 / HTML 标签 | ❌ | 建议改用 pandoc |

## 已知限制
* **跨 run 的括号不配对**：半角括号被粗体或行内代码拆成两个 run 时不会替换为中文括号（引号有跨 run 状态跟踪，括号没有）。写作 `结论 (即**主结论**)` 会保持半角，改为 `结论（即**主结论**）` 可避免。
* **链接 URL 含右括号**：`[文字](https://x.com/wiki/A_(b))` 会在第一个 `)` 处截断，建议改用 `%28` / `%29` 编码。
* **表格单元格内竖线**：不支持 `\|` 转义，会被当作列分隔符，导致列数变多、右侧出现空列。
* **粗体内不能再有星号**：`**` 包裹的内容里出现 `*` 会导致粗体不闭合。
* **图片宽度固定**：统一按 6.0 英寸插入，超宽图会溢出页面，需先自行缩放图片。
* **行内公式仅支持符号替换**：`\frac`、`\sum`、上下标等复杂公式不解析，建议改用 pandoc。
* **代码注释按标记识别，不做语法级解析**：只认常见注释标记（`#`、`//`、`--`、`/* */`、`<!-- -->`、ini 的 `;`），未标注语言时只按「行首标记」处理；`#` 开头的预处理指令与 shebang 会自动跳过，但非常规写法（如用 `//` 做字符串拼接、Rust 生命周期 `&'a`）仍可能被误判。

## 在 Agent 中使用
当需要转换 Markdown 到 Word 时，可直接使用如下指令：
* "把 document.md 转换为Word文档"
* "将当前目录下的所有.md文件转换为.docx格式"
* "把这个Markdown文件转换为Word，并在开头加上目录"（→ `--include-toc`）

Agent 会自动加载此 skill、自动读取同目录下的样式配置文件并执行转换。

## 故障排除
| 现象 | 原因与解决 |
| --- | --- |
| `ImportError: python-docx` | 未安装核心依赖：`pip install python-docx` |
| 修改样式未生效 | 确认 `custom_styles.json` 语法无误并置于脚本/SKILL 同目录下 |
| 图片不显示 | 必须是本地文件路径；网络 URL 图片需先下载到本地 |
| 代码高亮未生效 | 未安装可选依赖：`pip install pygments` |
| 输出目录不存在 | 脚本会自动创建父级输出目录 |
| 行内代码没有灰底 | 当前 `code.inline_code` 为 `false`，改为 `true` 即可恢复等宽字体 + 浅灰底 |
| 列表符号大小与正文不一致 | 检查 `list.bullet_size`，`"auto"` 表示跟随 `list.size` |
| 复选框点一下变成叉、再点变空框 | 旧版本把状态属性写成 `w:val`，Word 读不到状态会退回内置 ☒/☐ 字形；当前版本已改为 `w14:val`，重新转换即可 |
| 代码块注释没被清理 | 确认围栏后标注了语言（如 `python`、`javascript`）；未标注时只识别行首的 `#`、`//`、`--` |
| 代码块里的注释被误清理 | 该行可能被识别为注释，但实际是代码，给围栏补上语言标记可缩小识别范围，或者检查代码块清理规则 |
