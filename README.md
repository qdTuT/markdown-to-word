# 版本更新说明
> 说明详情见`SKILL.md`和`markdown_to_word.py`文件中的代码注释

## **1.1.0：初始化**
- 支持转换特性：粗体/斜体、列表（有序/无序）、任务列表、代码块、行内代码、链接、图片、表格、引用、分割线
- 不支持转换特性：脚注/复杂数学公式/HTML标签
- 自定义标题样式
- 文本空格清理
- 行内代码符号去除
- 标点替换

## **1.2.0：增强配置化与转换规则细化**
- 优化任务列表、有序/无序列表转换规则
- 新增JSON配置文件
- 新增“行内代码是否转换”开关
- 新增标题段落之后不保留空行规则
- 新增常用LaTeX箭头/符号支持（支持转换特性）
- 新增分割线符号删除且不保留空行规则（不支持转换特性）

## **2.1.0：统一格式并完善清理规则**
- 统一子列表符号前缩进与无序列表符号后缩进
- 优化字体行高规则
- 修改文本空格清理规范，并增加路径保护
- 修改并补充标点替换规则
- 新增不支持“粗体/斜体下划线写法”的转换（不支持转换特性）
- 新增单位/科学符号两侧转换规则
- 修改任务列表转换规范
- 为代码块注释增加空格与标点清理
- 进一步优化文本空格清理规则
