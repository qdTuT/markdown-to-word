## 粗体与斜体语法

* 双星号包裹即为粗体：这段是**粗体文字**，紧跟普通文字。
* 单星号包裹即为斜体：这段是*斜体文字*，紧跟普通文字。
* 中英混排同样生效：**加粗的中文**与 *italic English* 都要有样式。
* 粗体与斜体相邻：**粗体**紧接*斜体*，中间不产生多余空格。
* 下划线写法不再识别：__下划线粗体__ 与 _下划线斜体_ 原样保留字符，不产生粗体或斜体效果。
* 标识符不受影响：example_file_name 与 user_id 按普通文本输出，下划线不会被吃掉。

## 行内代码

当前 `custom_styles.json` 中 `inline_code` 为 `false`，行内代码按正文样式渲染，只去掉反引号、内容保持原样：

* 引号与括号不替换：`print("Hello, World!")` 转换后括号仍是半角，内容逐字保留。
* 空格不清理：`A → B` 转换后箭头两侧的空格仍在。
* 内容跳过标点替换：`使用 "x" 与 中文` 转换后引号仍是半角，不会与中文配对替换。
* 若把 `inline_code` 改为 `true`，上述内容会改为 Consolas 等宽字体 + 浅灰底色。

## 标点替换（前后语境 + 内容语境）

* 符号前面是中文：使用 "Pandoc" 库 → 预期变成中文引号。
* 符号后面是中文："DeepSeek模型" 很受欢迎 → 预期变成中文引号。
* 括号内部含中文：模型 DeepSeek-V4.1-Flash(很受喜爱) is great value for money. → 预期变成中文括号。
* 前后都不是中文、内容也无中文：DeepSeek said "hello" and thanks. → 预期保持原样。
* 括号内容为纯版本号时保持半角：模型 DeepSeek-V4.1-Flash(very beloved) is great value for money. 不会被替换为中文括号。
* 引号被粗体拆开：深度求索说 "**我们**很荣幸被受欢迎和喜爱"。→ 引号仍成对替换为中文引号，粗体样式不丢。

## 路径保护

* Windows 绝对路径中的括号不被替换：C:\Users\user1\示例(最终)文档.md
* URL 中的括号不被替换：https://example.com/a_(b)?q=1
* 相对路径同样受保护：./docs/(示例)/example.md
* 邮箱地址不受标点替换影响：dev.user@example.com

## 文本清理（空格归一化）

* 中文与英文之间：转换 Markdown documents 很常见 → 两处空格都被去除。
* 中文与数字之间：共 128 个字符 → 空格被去除。
* 字母与运算符之间：x = 1 + 2 → 贴合为 x=1+2。
* 数字与半角标点之间：hello , word ; example → 逗号、分号前的空格被去除。
* 全角标点两侧：你好 ， 世界 ！ → 全角标点两侧的空格被去除。
* 英文单词之间保留空格：hello world and more words 原样不动。
* 数字与数字之间保留空格：123 456 789 原样不动。
* 中文与中文之间同样去空格：源码「`这是 一段 中文`」渲染为「这是一段中文」；中间夹制表符、全角空格或多个连续空格，同样贴合为一个整体。

## 单位与科学符号间距

以下各行验证「左侧一律贴合、右侧看后接字符」：

* 前接数字：室温 30 ℃ 左右 → 渲染为 室温30℃左右。
* 全角百分号：效率 90 ％ 左右 → 渲染为 效率90％左右。
* 半角百分号：进度 90 % 完成 → 渲染为 进度90%完成。
* 箭头夹在中文之间：输入 → 大模型 → 输出 → 渲染为 输入→大模型→输出。
* 箭头夹在英文之间：流程 A → B → C 结束 → 渲染为 流程A→B→C结束。
* 角度符号后接字母：角度 25 ° C → 渲染为 角度25°C。
* 符号右侧后接英文单词：Cool to 30 ℃ and hold. → 单位贴合数字，但与 and 之间保留一个空格。
* 符号右侧后接数字或中文：90 % 的样本、30 ℃ 5 分钟 → 右侧空格同样被去除。
* 比较符号：误差 ≤ 5 % 以内 → 渲染为 误差≤5%以内。
* 波浪号区间：范围 10 ~ 20 之间 → 渲染为 范围10~20之间。
* 英文语境下的非贴合符号：a ≠ b 中的 ≠ 不属于「字母也贴合」组，字母两侧空格保留。

## 代码块

带语言标记的代码块：代码本体原样保留，**注释内容按正文规则清理**（中英去空格、引号括号按语境替换）。

```python
def func_hello(name):
    # 中文 English 混排与 "引号" 会被清理
    print(f"Hello, {name}")  # 设置 x = 1 的值
    return "# 不是注释，原样保留"
```

预期：第 2 行渲染为 `# 中文English混排 与“引号”会被清理`，第 3 行尾注释渲染为 `# 设置x=1的值`，`return` 行里的字符串一个字符都不变。

C 系语言用 `//` 与 `/* */`，字符串里的 `//` 不会被误判：

```javascript
const url = "https://example.com/a_(b)";  // URL 与括号保持原样
/* 单行块注释：中文 English 混排 */
const half = 10 / 3;  // 除号两侧空格保留
```

预期：注释被清理，`"https://..."` 与 `10 / 3` 原样保留。

不带语言标记时按「行首标记」保守识别，本段没有注释标记，整段原样输出：

```
30 ℃ / 90 % / A → B
这些符号两侧的空格在代码块内不会被清理
```

## LaTeX 行内符号

* 箭头：\(A \rightarrow B\) → 渲染为 A→B；\(X \leftarrow Y\) → 渲染为 X←Y。
* 蕴含：\(P \Rightarrow Q\) → 渲染为 P⇒Q；\(P \Leftrightarrow Q\) → 渲染为 P⇔Q。
* 比较（数字语境贴合）：\(3 \leq 5\) → 渲染为 3≤5；\(7 \geq 2\) → 渲染为 7≥2。
* 比较（字母语境保留空格）：\(a \neq b\) → 渲染为 a ≠ b。
* 运算：\(3 \times 5 = 15\) → 渲染为 3×5=15；\(8 \div 2 = 4\) → 渲染为 8÷2=4；\(5 \pm 1\) → 渲染为 5±1。
* 其他符号：\(\approx\) → ≈；\(\infty\) → ∞。

## 中英混排与双引号字体

这一节验证混合排版：中文使用宋体，English 使用 Calibri，数字 123 同样走西文字体。中文双引号“应单独拆成一个 run 并用东亚字体渲染”，避免 Word 用 Calibri 渲染引号导致字重、字宽不一致。
